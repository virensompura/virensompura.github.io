01Project overview

A prototype autonomous mobile robot that maps obstacles in real time with a 2D LiDAR and plans collision-free paths with the A* search algorithm.

Objective

Demonstrate real-time obstacle mapping and path planning on low-cost compute.

My contribution

  • Built the AMR prototype with a Raspberry Pi 4 for ROS integration and an Arduino Mega for low-level hardware control.
  • Implemented real-time obstacle mapping with an RPLiDAR A1M8.
  • Implemented navigation using the A* search algorithm.
