Getting Started with ROS2: Complete Installation & Workspace Setup

By Viren Sompura · Mar 2025 · 10 min read

🤖 Article

Introduction

ROS2 (Robot Operating System 2) is the industry-standard middleware for building robotic systems. Unlike ROS1, it's built on DDS (Data Distribution Service), offers real-time capability, and supports multiple platforms including Linux, Windows, and macOS.

In this guide, we'll install ROS2 Humble on Ubuntu 22.04 LTS — the most stable and widely-used combination for production robotics work.

1. Set Up Locale

locale  # check for UTF-8

sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

2. Add the ROS2 Repository

sudo apt install software-properties-common
sudo add-apt-repository universe

sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key \
  -o /usr/share/keyrings/ros-archive-keyring.gpg

echo "deb [arch=$(dpkg --print-architecture) \
  signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] \
  http://packages.ros.org/ros2/ubuntu \
  $(. /etc/os-release && echo $UBUNTU_CODENAME) main" \
  | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null

3. Install ROS2 Humble

sudo apt update && sudo apt upgrade -y
sudo apt install ros-humble-desktop

4. Configure Your Environment

Add this to your ~/.bashrc so ROS2 is available in every terminal:

echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc
source ~/.bashrc

5. Create Your First Workspace

mkdir -p ~/ros2_ws/src
cd ~/ros2_ws
colcon build
source install/setup.bash

6. Test Your Installation

Open two terminals and run the classic talker-listener demo:

# Terminal 1
ros2 run demo_nodes_cpp talker

# Terminal 2
ros2 run demo_nodes_py listener

Key Concepts to Know

  • Workspace: A directory where you build and store ROS2 packages
  • Package: The fundamental unit of ROS2 software organization
  • colcon: The build tool used in ROS2 (replaces catkin_make)
  • ament: The build system used by ROS2 packages
