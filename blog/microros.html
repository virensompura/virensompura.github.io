micro-ROS: Bringing ROS2 to Microcontrollers

By Viren Sompura · Aug 2025 · 13 min read

🔌 Article
Use the back links below to return to the full blog list or the home page.

What is micro-ROS?

micro-ROS extends the ROS2 ecosystem to resource-constrained microcontrollers. Instead of a full Linux-based node, you get a lightweight client that communicates with a ROS2 network through a micro-ROS Agent running on a host machine.

Supported Platforms

  • STM32 series (F4, H7, U5)
  • ESP32 and ESP32-S3
  • Arduino (limited)
  • Raspberry Pi Pico (RP2040)

Architecture

micro-ROS uses a client–agent model:

  • MCU: Runs the micro-ROS client, publishers, subscribers, timers
  • Agent: Runs on the host PC, bridges micro-ROS to full ROS2 DDS
  • Transport: Serial, UDP, or USB

ESP32 Example: IMU Publisher

#include <micro_ros_arduino.h>
#include <sensor_msgs/msg/imu.h>

rcl_publisher_t imu_pub;
sensor_msgs__msg__Imu imu_msg;

void setup() {
  set_microros_transports();
  rcl_node_t node;
  rclc_node_init_default(&node, "imu_node", "", &support);
  
  rclc_publisher_init_default(
    &imu_pub, &node,
    ROSIDL_GET_MSG_TYPE_SUPPORT(sensor_msgs, msg, Imu),
    "imu/data"
  );
}

void loop() {
  imu_msg.linear_acceleration.x = readAccelX();
  rcl_publish(&imu_pub, &imu_msg, NULL);
  delay(10); // 100 Hz
}

Running the Agent

# Install micro-ROS agent
pip install micro-ros-agent

# Start agent over serial
ros2 run micro_ros_agent micro_ros_agent serial \
  --dev /dev/ttyUSB0 -b 115200

FreeRTOS Integration

For time-critical systems, run the micro-ROS executor within a dedicated FreeRTOS task:

void microros_task(void *args) {
  rclc_executor_t executor;
  rclc_executor_init(&executor, &support.context, 4, &allocator);
  
  while(1) {
    rclc_executor_spin_some(&executor, RCL_MS_TO_NS(10));
    vTaskDelay(pdMS_TO_TICKS(10));
  }
}

Why micro-ROS?

Direct integration of low-level hardware into the ROS2 graph means no ROS-serial bridges, no custom protocol parsers — just native topics and services across your entire robot system from MCU to cloud.
