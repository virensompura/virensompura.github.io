What is Nav2?

Nav2 (Navigation2) is the standard navigation stack for ROS2. It provides a complete solution for autonomous robot navigation including path planning, obstacle avoidance, and behavior trees for high-level task orchestration.

Core Components

  • Planner Server: Computes globally optimal paths (NavFn, Smac)
  • Controller Server: Executes local trajectory tracking (DWB, MPPI)
  • Costmap 2D: Represents free, occupied, and unknown space
  • BT Navigator: Orchestrates the navigation behavior tree
  • AMCL: Adaptive Monte Carlo Localization for position estimation

Minimal Nav2 Launch

from launch import LaunchDescription
from launch_ros.actions import Node

def generate_launch_description():
    return LaunchDescription([
        Node(
            package='nav2_bringup',
            executable='bringup_launch.py',
            parameters=[nav2_params_path]
        )
    ])

Sending a Navigation Goal

from geometry_msgs.msg import PoseStamped
from nav2_simple_commander.robot_navigator import BasicNavigator

navigator = BasicNavigator()
goal = PoseStamped()
goal.header.frame_id = 'map'
goal.pose.position.x = 2.0
goal.pose.position.y = 1.5
goal.pose.orientation.w = 1.0

navigator.goToPose(goal)
while not navigator.isNavComplete():
    feedback = navigator.getFeedback()

Costmap Configuration

The costmap is the robot's representation of the world. Key parameters:

global_costmap:
  ros__parameters:
    update_frequency: 1.0
    publish_frequency: 1.0
    global_frame: map
    robot_base_frame: base_link
    use_sim_time: false
    robot_radius: 0.22
    resolution: 0.05

Tips from the Field

  • Always tune the inflation radius to slightly larger than your robot's footprint
  • Use the Smac Planner for smoother, curvature-constrained paths
  • MPPI controller handles dynamic environments better than DWB
  • Set transform_tolerance generously (0.5s) during development
